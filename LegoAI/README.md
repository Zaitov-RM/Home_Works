# 🤖 LegoAI — «ИИ-операционная система» для LEGO-конструктора на ESP32

Образовательная платформа: дети собирают роботов/механизмы из LEGO с датчиками
на ESP32 и **обучают** их — от простых правил до нейросетей, которые обучаются
прямо на плате (TinyML) или рядом с компьютером.

## Архитектура (3 слоя)

```
┌─────────────────────────────────────────────────────────┐
│  Веб-редактор в браузере (блоки/Python, джойстик)        │
├─────────────────────────────────────────────────────────┤
│  LegoAI OS на ESP32 (MicroPython):                        │
│   • drivers/   — моторы, серво, датчики (LEGO-совместимо)│
│   • behavior/  — «поведения»: реактивные правила, FSM,    │
│                  Q-learning, политика на нейросети        │
│   • ml/        — крошечный фреймворк НС on-device         │
│   • storage/   — сохранение моделей/датасетов во flash    │
│   • web/       — Wi-Fi REST API + телеметрия             │
├─────────────────────────────────────────────────────────┤
│  Сервер обучения (компьютер, Python) — server/            │
│   симулятор, тяжёлое обучение, экспорт весов на ESP32    │
└─────────────────────────────────────────────────────────┘
```

## Железо (пример конфигурации)

| Модуль | Пример | Порты ESP32 |
|---|---|---|
| Моторы LEGO PF через DRV8833 | 2× DC | GPIO 25, 26 (PWM) |
| Серво WG9000 | 1× | GPIO 27 (PWM) |
| Ультразвук HC-SR04 | дальномер | GPIO 4 (trig), 5 (echo) |
| Линейка TCRT5000 ×3 | линия | GPIO 32, 33, 34 (ADC) |
| LED-матрица 8×8 | «эмоции» | I2C GPIO 21, 22 |
| Кнопки «умница / ошибка» | обучение с учителем | GPIO 35, 36 |

## Быстрый старт

1. Прошейте ESP32 MicroPython (https://micropython.org/download/esp32/):
   ```bash
   esptool.py --chip esp32 erase_flash
   esptool.py --chip esp32 --port /dev/ttyUSB0 write_flash -z 0x1000 \
       firmware/micropython-esp32.bin
   ```
2. Скопируйте систему на плату:
   ```bash
   pip install mpremote
   mpremote cp esp/* :
   mpremote reset
   ```
3. Плата создаёт точку доступа `LegoAI-XXXX` (пароль `legoai4kids`) —
   подключитесь браузером к `http://192.168.4.1`: редактор Python,
   джойстик, обучение, мониторинг датчиков.
4. Симулятор и «взрослое» обучение на компьютере:
   ```bash
   python server/simulator.py          # тренажёр Q-learning без железа
   python server/train_and_export.py   # NN-политика -> веса для ESP32
   ```

## Как дети «обучают ИИ» (урок за уроком)

1. **Рефлексы**: `если расстояние < 20 см → назад` (правила).
2. **Конечный автомат**: «ищет шарик → едет → хватает → возвращается».
3. **Обучение с подкреплением (Q-learning)**: робот в лабиринте получает
   −1 за шаг, −10 за стену, +100 за выход; таблица Q сохраняется во flash.
4. **Обучение демонстрацией (имитация)**: ребёнок водит робот кнопками/
   джойстиком в браузере, система собирает датасет `(состояние -> действие)`
   и обучает нейросеть-политику прямо на ESP32 (ml/network.py).
5. **Компьютерное зрение** (по желанию): ESP32-CAM + сервер — робот видит
   цветные кубики и сортирует их по командам.

## Структура папок

* `esp/drivers/` — драйверы моторов/серво/датчиков (безопасный PWM ≤ 70%)
* `esp/behavior/` — правила, FSM, Q-learning, NN-политика
* `esp/ml/` — крошечный фреймворк нейронок (forward+backprop, чистый Python)
* `esp/storage/` — JSON-сохранения моделей и датасетов во flash
* `esp/web/` — HTTP-сервер: API обучения, телеметрия, редактор
* `esp/main.py` — загрузчик ОС
* `server/` — симулятор + обучение на ПК + экспорт весов
* `lessons/` — планы уроков

## Безопасность для детей
* Питание моторов — отдельная батарея, общая земля, конденсаторы 100 мкФ.
* Прошивка ограничивает PWM моторов 70% и скорость серво.
* Все модели версионируются; «сброс к заводским» — одна кнопка/команда.
